SAP SuccessFactors foundation object sync

SAPSF ObjectSync

Production-grade utility to synchronise SAP SuccessFactors Organisational Management foundation objects from a source tenant to a lower target tenant through OData v2.

View GitHub repo Quick start Sample input

Sync flow

1. Input
Provide Sub Department or Department codes.
2. Resolve
Automatically walk ancestors to Division, Business Unit, and Legal Entity.
3. Preview
Dry-run first with reports and logs before writes.
4. Sync
Apply controlled updates to the target tenant.
5 supported object levels
3 auth modes
2 interfaces: CLI and web UI
1 audit trail per run

Safety first

  • Dry-run mode defaults to safe preview.
  • Credentials stay local in `.env`.
  • Output logs and Excel reports support review.

Consultant use case

  • Seed lower tenants after PRD changes.
  • Keep Dev and Test aligned.
  • Reduce manual foundation object copy work.

Supported stack

  • Python CLI and library.
  • Flask web UI.
  • Basic, OAuth, and certificate auth options.
